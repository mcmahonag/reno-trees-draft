Data

Team database

Everyone signed in shares the same trees, work and requests. Work offline as usual; changes upload a few seconds after you save, and other people's changes arrive within about 20 seconds.

Database connection

Team & crews

Set each person's role. Admins see everything. Crew accounts see the tree inventory plus only the work records and work orders whose Crew or Assigned to field includes their crew code (for example LP), and anything they flag themselves.

Import from TreePlotter

Select one or more CSV exports: trees, work records, work orders, inspections and service requests. The app recognizes each file. Re-importing updates records by their TreePlotter ID and keeps anything you've changed in this app. When you're signed in to the team database, imported records are uploaded for everyone, so only one person needs to import.

Back up and move devices

Everything lives on this device only. Save a backup regularly, and restore it to move your data to another phone or computer.

Move data by file

Without the team database: send a changes file from one device and merge it on the other. Where the same record was edited on both, the newer edit wins.

Export

Spreadsheets for the office or for entering updates in TreePlotter. "Changed here" exports only what was added or edited in this app.
